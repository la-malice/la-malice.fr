# Decouverte du futur site

Ce dossier accueille les sources de la phase de decouverte. Il doit permettre a Emilie de distinguer ce qui est connu, ce qui est suppose et ce qui lui est propose.

## A produire

1. `brief.md` : transcription fidele du brief minimal, avec sa source et sa date.
2. `questions-ouvertes.md` : questions, proprietaire, impact et reponse attendue.
3. `recherche.md` : constats verifies sur La Malice, ses publics et les solutions existantes.
4. `propositions.md` : options comparables a presenter a Emilie, sans les confondre avec une decision.

Ne pas remplir ces documents avec des suppositions pour faire avancer le projet. Une proposition peut contenir des hypotheses, a condition de les nommer et de dire comment les valider.

## Premier atelier recommande

Utiliser `bmad-project-context` avec le brief d'Emilie et cette gouvernance. L'objectif est d'obtenir un cadre de projet partage, pas de choisir une stack ni de produire des maquettes finales.
